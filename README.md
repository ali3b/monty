# Monty — Montezuma's Revenge, rebuilt through Synty Sprite Generator

A Phaser 3 remake of Parker Brothers' *Montezuma's Revenge* (Robert Jaeger, 1984). Panama Joe climbs down into an
Aztec tomb room by room: ladders and ropes, three colours of locked door, five pockets, bouncing skulls, fire and
crumbling floors, and darkness that creeps up the pyramid one level at a time.

Every sprite and every ground tile in the game is generated by
[Synty Sprite Generator](https://github.com/andrew/synty-sprite-generator) — Joe and the skeleton are rigged
characters, everything else is a prop, and the tomb's walls, floor and ledges are a ground tileset.

```
npm install
npm run assets      # build every sprite and the tileset through the generator (writes public/assets)
npm run dev         # http://localhost:5197
```

`npm run dev` before `npm run assets` shows an "ASSETS MISSING" notice; the assets are build output, not source.

## Playing

Arrows or WASD.

| | |
|---|---|
| Left / right | walk |
| Up / W / Space | jump, or grab a ladder |
| Down / S | crouch, ride a rope down, climb down |
| Left / right on a ladder | step off sideways onto a platform |

Gold, silver and red keys open the doors of the same colour, so the way down depends on what you picked up on the
way. A dagger takes one creature; the torch lights the dark rooms; a fall further than Joe is tall kills him, as in
the original. Take the idol in the shrine, grab what you can in the bonus room, and go deeper.

## Checks

```
npm run typecheck
node scripts/check-rooms.mjs                       # the pyramid: ladders, ledges, items and doors
npm run dev &
node scripts/load-check.mjs http://localhost:5197 room      # standing, walking, jumping, a key, a door, a ladder
node scripts/load-check.mjs http://localhost:5197 flow      # the idol, the bonus room, level 2, the dark and the torch
node scripts/load-check.mjs http://localhost:5197 deaths    # fire, and a fall that kills
node scripts/load-check.mjs http://localhost:5197 gameover  # the last life, and the game over screen
node scripts/tour.mjs                              # a screenshot of every room into test-results/rooms/
```

The checks drive the real game in a browser over CDP and only use `?scene=`, `?room=` and `?level=`, so any room
can be opened directly: `http://localhost:5197/?scene=room&room=fire&level=6`.

## Layout

| | |
|---|---|
| `ssg.assets.json` | every sprite and the tileset the game uses, by name |
| `scripts/build-assets.mjs` | applies that file with the `ssg` CLI, renders, downloads, and writes `manifest.json` |
| `scripts/make-rooms.mjs` | prints room art from a compact spec (the rooms are hand-tuned ASCII) |
| `scripts/check-rooms.mjs` | the layout rules the pyramid has to keep |
| `src/rooms.ts` | the rooms, as ASCII art, one character per tile |
| `src/world.ts` | the collision: a box moved against the tile grid |
| `src/joe.ts` | Joe: the fixed-length jump, ladders, ropes and the fall that kills |
| `docs/DESIGN.md` | what the original does, and where this remake differs |
| `FEEDBACK.md` | what the generator could not give us (FB-001 … FB-008) |
